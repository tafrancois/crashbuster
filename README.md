# crashbuster
Tracking sugar intake to prevent sugar crashes.

Crash Buster 💥🍩 is a PWA for tracking added sugar, riding out cravings, and racking up wins.

- **Today**: daily sugar ring (35g goal, 40g PMS/period mode), quick log buttons, timestamped timeline
- **Journal**: longer reflections plus filterable history
- **Toolkit**: My Why, Moves (strategies), Goals
- **Wins**: weekly points, streaks
- Gemini API (free key) estimates added sugar from photos or text

All data stays on-device (IndexedDB). Export backups from ⚙️ Settings.
